# U5InValheim — project notes

Ultima V rebuilt inside Valheim (BepInEx + Jötunn). `MASTER_PLAN.md` is the backbone; the three
`.txt` design notes are the user's authority on mappings, actions and restrictions.

## Layout
- `src/U5InValheim/` plugin. `Data/` = Unity-free readers of the player's Ultima V files (shared with
  tests and tools by `<Compile Include ... Link>`); `Data/Dg.cs` is generated by `tools/gen_dgroup.py`
  from `~/Projects/Ultima5Revolutions/analysis/globals_seed.jsonl` (DGROUP = DATA.OVL file offset − 0x10).
- `assets/mappings/*.json` U5 → Valheim tables; deviations go in `docs/MAPPING_DECISIONS.md`.
- `tests/U5InValheim.Tests` xunit (net8). Data tests need `$U5_DIR` (default `~/Projects/Ultima 5`),
  skipped otherwise. Golden files: `tools/rustref` (runs the Rust port's lzw.rs) and `tools/pyref.py`
  (runs generate_terrain.read_u5); only hashes/coordinates are stored.
- `tools/U5Dump` offline twin of the in-game `u5 dump` command: `dotnet run --project tools/U5Dump -- npcs Britain`.
- `src/U5InValheim/World/` (namespace `U5InValheim.WorldGen`; not `.World`, which would hide Valheim's
  `World`): `Core/` is Unity-free (BritanniaShape = height/biome of the U5 map, periodic for the wrap;
  TerrainTable; Pois) and linked into tests/U5Dump; the rest are Harmony patches.
- A world is Britannia iff its seed name starts with "Britannia" (synced to clients by vanilla);
  `NewWorldsAreBritannia` makes World.GenerateSeed return such seeds.
- Town plans: `dotnet run --project tools/U5Dump -- town <loc> floors` prints each storey (# wall, + opening, o inside/walked, ~ water); `town <loc> probe <z> <x> <y>` explains one tile; `town <loc> out.json` + `tools/render_town.py` renders it.
- Offline terrain preview: `dotnet run --project tools/U5Dump -- preview out.ppm [px] [extraTiles]`; `slopes [step]` prints slope percentiles per terrain class; `dressing` counts the edge plants and rocks (`dressing.json`); `banners out.ppm [tiles]` draws the shop banners printed from TILES.16; `sites 2,17,19` shows where settlements are built (moved apart) and the land there. `shops Britain` shows its shopkeepers (hours, greeting, stock, farewell); `converse Britain Justin name job bye` plays a conversation as the in-game panel shows it (`talk <loc> <slot>` decodes a script).
- Townsfolk: `World/Townsfolk.cs` (prefab `u5_townsperson` = the Player prefab turned into a plain Humanoid, a real creature; patches in `TownsfolkPatches.cs`; spawned per settlement zone) drives `Core/TownWalker` (schedule + paths, Unity-free, tested by simulating a day); a dedicated server unloads them with no player near; the self-test holds that off and generates Britain's zones (ZoneSystem.CreateLocalZones) so they walk on real ground. The town alarm is `World/TownWatch.cs` (rules in `Core/TownAlarm.cs`); with SelfTest on, a server plays three alarm scenarios in Britain (greyling, troll, guards down) and logs them (`townsfolk self-test alarm`), plus forced encounters, a plain Valheim troll turned Ettin, the hover text and walking smoothness (`smooth: N/M walking samples stalled`). A townsperson must `SetWalk(true)` to move at `m_walkSpeed` (else Valheim's jog speed). `Character` is the first `Hoverable` on their body, so its hover is patched to the TownNpc's. `U5_SELFTEST=town:<location>[,<location>…]` builds just those settlements (a list: one 20 s check each; any `U5_SELFTEST` run logs `townsfolk self-test done` and shuts the server down; `U5_SELFTEST=all` runs the whole test that way, while SelfTest on alone keeps the server up) and checks its pieces, statues and that its people keep to their floors; `U5_SELFTEST=crime` in the server's environment runs only the castle's ballista, arrest (a disabled Player body as the stand-in: an owner destroys any Player but its local one) and Yew jail scenarios. Crime and arrest: `World/Crime.cs`; ballistas: `World/Ballistas.cs`; locked doors, secret walls (bricks with ZDO `u5_secret` group, the door behind `u5_hidden`): `World/TownDoors.cs`. The crime self-test also checks Yew's jail (prisoners, locked cell door, the secret wall, trapdoors, ladders) and logs what the ballista bolts hit. In-game `u5 encounter` (devcommands) forces a random encounter; the encounter rate is the original's (none on daytime grassland).
- Items: `Data/ItemMap.cs` reads items.json into one catalogue (ItemDef: our prefab `U5_<name>`, its Valheim base, kind, Ultima id, tint); `World/UltimaItems.cs` makes each a Jötunn CustomItem with the Ultima name and numbers and recolours tinted ones (textures and icons, read back through the GPU) on machines that draw. Combat finds an item's Ultima id with `ItemMap.EquipmentOf(prefab)`.
- Loot: `Data/Loot.cs` (Unity-free: chest rolls, monster drops, hidden objects, .NPC objects, gifts; tested) and `World/Treasure.cs` (`u5_chest` filled when it appears, traps on first open; `u5_loot` spots taken or searched with E, placed with each settlement zone and out in the land). The town self-test logs the settlement's chests and loot spots and kills 12 trolls to count the chests they leave; delete the scratch world (`$SP/save/worlds_local/U5Shells/*`) to see loot placed (it only happens when a zone is first made).
- Harpsichord: `World/Harpsichord.cs` (look "harpsichord" on the 0x8d black forge; E asks for digits; `Data/Melody.cs` is the original's matcher); the whole melody toggles the "tune" walls within 40 m (Lord British's castle (17,13) z2, made one by `tile_at` in town_tiles.json), the way to the Sandalwood Box. `u5 play <notes>` plays the harpsichord you stand at.
- Use items, worn items, keys: `Data/ItemUse.cs` (Unity-free: sextant position, watch, jimmy odds, ring rolls, the telescope's night sky, status.json looks; tested); `World/UseItems.cs` (right-click handlers, gem-only map, the sky panel), `World/WornEffects.cs` (rings, regalia party effects, invisibility, Klimb), `World/MagicCarpet.cs` (`u5_magic_carpet`), `World/BlackthornGuards.cs` (badge + password), jimmy/skull keys in `World/TownDoors.cs`. `U5_SELFTEST=items` logs them (`items self-test`).
- Time and the story's clockwork: `World/Calendar.cs` (`Calendar.Now`/`Hour`/`WorldDay`/`Moons`, read from Valheim's clock; first world day = INIT.GAM's 4-5-139; `WorldKeys` = global keys), `World/Moongates.cs` (gates at buried moonstones by night, client-drawn `portal_stone` look; sites in global keys `u5_moonstone<n>`; using a moonstone buries it), `World/Shadowlords.cs` (travels by the calendar, town effects via `TownNpc.Sway`, yell + shard doom); Unity-free rules in `Core/Clockwork.cs` (ClockworkTests). `u5 time|moons|dusk|dawn|midnight`; `U5_SELFTEST=clock` (DevTools/ClockSelfTest).
- Sleep, inns and camps: `World/Sleep.cs` (day sleep, camp ambush), `World/Inns.cs` (rent; beds of `SettlementPlan.InnRooms`), `World/Camp.cs` (H: lean-to prefab `u5_leanto` + fire_pit). `U5Dump town <loc> inn` shows an inn's rooms and beds; `U5_SELFTEST=sleep` (`U5_SLEEP_TOWN=<loc>` for another inn) checks Britain's inn beds and pitching/moving/refusing a camp (sleeping itself needs real players).
- Karma, food, restrictions, intro (§5.9, §5.12, §5.13): `Data/Karma.cs` (key `u5_karma`; deeds' constants) + `World/KarmaDeeds.cs` (`Change(player, delta, why)`, any machine); `Data/Rations.cs` + `World/Rations.cs` (one Barley a day, else 30 % health); `World/Restrictions.cs` (trees, rocks, terrain, crafting, planting, the hut's tools); `Data/Pictures.cs`/`Data/Story.cs` draw the original's 320×200 screens (`U5Dump intro <dir>` writes them as PPMs), shown by `World/UltimaScreenPanel.cs`; `World/Intro.cs` (per character and world, `u5 intro`); `Data/Virtues.cs` (the gypsy) + `World/IolosHut.cs` (Hildir `u5_hildir`, door lock, player ZDO `u5_made`; `u5 unmake` with devcommands). Shrines: `Data/Shrines.cs` (texts, mantras, `ShrineRules`) + `World/Shrines.cs` (built from MISCMAPS.DAT maps; kneeling stone `u5_shrine_altar`; `Desecrate`/`Restore` world keys, `Visit` for Spirituality). `U5_SELFTEST=hut` checks Hildir, the lock, a tree, recipes and the intro files.
- Settlement creatures: `World/ResidentMonster.cs` (silent ones, by their AI type). Talking creatures (Sin'Vraal, Grendel, Balinor): `World/CreatureTalker.cs`, a creature body with AI off on the players' faction; `TalkPanel` takes any `ITalker`.
- Magic: `Data/Magic.cs` (Unity-free: spell table from DATA.OVL, recipes, the cast's checks, evasion, potions, times; tested), `World/Spells.cs` (cast key Z = Magic/CastKey on the readied spell in the ammo slot, mana on the eitr bar, M by a fire, scrolls/potions on right-click), `World/SpellEffects.cs` (the 48 spells, scrolls, potions; hooks InDungeon/DungeonLadder/GateTravel for other systems; spell hits carry m_skill ElementalMagic), `World/SpellStatus.cs` (player status effects; creature sleep/fear/charm/stop/confuse/summoned as ZDO times obeyed in MonsterAI.UpdateAI; Fx shown on all peers), `World/MixPanel.cs`.
- The Ettin (`World/Ettin.cs`): a Troll clone with the frost troll trophy grown live as a second head (`EttinHead` turns it, `EttinShoulders` moves the first head over), red by hue-turning its textures on machines that draw. Valheim's own forest troll trophy has no mesh: when a prefab draws nothing, read the game's assets with UnityPy in a scratch venv (`UnityPy.load(valheim_Data)`, find the GameObject, follow its MeshFilter m_Mesh) rather than guessing; nothing extracted is kept.
- Dungeons: `World/Core/DungeonPlanner.cs` (Unity-free: each level an 88x88 grid of the original's 11x11 combat maps, features, room contents/triggers, words of power; tested) → `World/Dungeons.cs` (entrance prefab `u5_dungeon_entrance` placed with its zone, holding the dungeon's state in its ZDO; words of power from `Chat.SendText`; enter/exit/climb) and `World/DungeonRunner.cs` (builds levels near players at y = 5000 − 8·level above the entrance as local meshes, hazards, rooms, doors, fountains, secret walls). `U5Dump dungeon <name> <level> plan` draws a level; `room <dungeon> <n>` a room; `u5 dungeon <name>` (devcommands) goes to an entrance. `U5_SELFTEST=dungeon[:0-7]` (default Destard) builds the entrance and every level, fills and clears a room, fires a trigger, finds a secret door (`dungeon self-test:` lines). The Underworld exit is the hook `Dungeons.UnderworldExit`.
- Story scenes: `Data/CutScene.cs` (the original's map window: MISCMAPS room, TILES.16 figures, move scripts, IBM.CH text column), `Data/Blackthorn.cs` (interrogation), `Data/Ending.cs` (Lord British's prison, END screens, certificate), all Unity-free iterators of `Beat`s (tested in StoryTests); `World/StoryScenes.cs` plays them on `UltimaScreenPanel` (`ScenePlayer`), `BlackthornCapture` (palace arrests, from `Crime.Watch`), `Endgame` (hook `Endgame.DoomMirror` for the Underworld's Doom; world key `u5_lb_freed`). `U5Dump scene blackthorn|endgame <dir> [answers] [party=N] [box]` writes the stops as PPMs; `u5 blackthorn`, `u5 endgame [box]` (devcommands), `u5 quest`; `U5_SELFTEST=story`.
- Load pauses: `DevTools/LoadProfiler.cs` (config Development/LogHitches, on by default) logs every frame over 150 ms as `hitch N ms:` with the timed sections in it (SpawnZone, Heightmap.Generate, PlaceVegetation, CreateDestroyObjects/CreateObject, our settlement pieces, townsfolk, structures with the objects/renderers/colliders they built, Settlements.Prepare, Minimap.GenerateWorldMap) and the untimed rest; measure on a client (a headless server neither draws nor creates the same objects). Calls over 500 ms are logged with their stack (`slow call`). Found that way: Valheim's terrain builder keeps only 16 finished builds, so flying over new land evicted a zone's terrain between its ready check and its use and the game waited at the back of the queue; `World/TerrainQueue.cs` puts a waited-on build first and keeps 64.
- `tools/data/valheim_prefabs.txt` prefab inventory (`tools/extract_prefabs.sh` after Valheim updates).

## Build / test / ship
- `dotnet build U5InValheim.sln` · `dotnet test tests/U5InValheim.Tests`
- Builds against the dedicated server's Managed DLLs (`VALHEIM_SERVER_DIR`); Jotunn from `lib/Jotunn.dll`.
- `tools/deploy.sh [valheim dir]` copies DLL + mappings into `BepInEx/plugins/U5InValheim/`.
- `tools/package.sh` checks manifest/Plugin.cs/CHANGELOG versions agree and zips `release/tarbaby-U5InValheim-<v>.zip`.
- Publish categories: `ai-generated client-side server-side` (via the mcp-valheim `publish` tool; verify
  categories on the listing afterwards).
- Client checks without the user: `~/Projects/AutoHeim` (its `valheim-client` skill; `tools/autoheim` from that repo) runs an isolated client whose profile is `~/.local/share/AutoHeim/instances/default/BepInEx` (Jötunn and the U5InValheim config copied in; `tools/deploy.sh ~/.local/share/AutoHeim/instances/default` after `autoheim quit`). Worlds named with a `Britannia…` seed; `world_objects name=u5_loot` finds loot, `teleport`/`look`/`screenshot` show hover text, `interact name=u5_loot` takes the nearest spot.
- Runtime checks: mcp-valheim control `start_server` / `start_client`, then read `BepInEx/LogOutput.log`
  for `U5InValheim v… loaded.` and `Read Ultima V from … ms`.

## Gotchas
- Never overwrite the DLL of a running Valheim in place: Mono maps it and the loaded assembly gets
  corrupted (garbled names, ExecutionEngineException on the next world load). `tools/deploy.sh`
  writes a temp file and renames it; the game must be fully restarted to pick up a deploy.
- A Britannia world that fails to build (Britannia.Failure) stops zone/location generation instead
  of falling back to vanilla, which would be saved into the world.
- `lib/Jotunn.dll` is 2.30.2 (the Valheim 1.0.7 update). 2.29 could not build this Valheim's
  `Terminal.ConsoleCommand`; console commands are registered the vanilla way anyway (postfix on
  `Terminal.InitTerminal`), which survives Jötunn lagging behind a Valheim release.
- `ZoneSystem.GenerateLocationsTimeSliced(location, …, iterationsPkg)` must write an int to
  `iterationsPkg` (the caller reads it back) even when skipped.
- Throwaway server test: copy the server to scratch, delete line 70 of its `run_bepinex.sh`, run with
  `-public 0 -savedir <scratch>`; dedicated servers generate no zones until a player joins.
- The server's `run_bepinex.sh` APPENDS its own default args (`-name "My server" -port 2456 -world
  Dedicated -password secret`), overriding yours. Don't use it for throwaway tests without removing line 70.
- No Ultima V data may be committed or packaged (.gitignore blocks the file types).
- Ultima data quirks (Mario's shifted TLK sections, rooms instead of ladders in Destard/Shame/Doom,
  Ararat in the Underworld) are documented in docs/MAPPING_DECISIONS.md — reproduce the original, don't "fix".
